# Install in local Codex

From this extracted folder, add the marketplace:

```bash
codex plugin marketplace add .
```

Then open Codex Plugins, find `d2l-sales-workflows`, and install it.

The public-repo bundle contains 20 sales skills. Two customer-story matching
skills and the Pat Voice skill were intentionally omitted because they embed
named-customer or named-organization proof points sourced from private
SharePoint. Keep the folder in a stable location so
the local marketplace path remains valid.

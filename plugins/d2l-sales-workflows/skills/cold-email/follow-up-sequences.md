# Follow-Up Sequences

Follow-up should add a new useful angle, not repeat the first email louder.

## Default Cadence

- Touch 1: first email.
- Touch 2: 3-5 business days later with a different angle or proof point.
- Touch 3: 5-7 business days later with a lighter resource or question.
- Touch 4: breakup only when the user asks for a longer sequence.

## Angle Rotation

Use one angle per touch:

- operational pain
- member or learner experience
- compliance or credentialing risk
- peer/customer proof
- practical resource
- timing or priority check

## Stop Conditions

Stop or pause when the next touch would repeat the same weak angle, rely on an unverified claim, or
feel more aggressive than the evidence supports.

## Final Deliverable

Return each touch with timing, channel, message angle, CTA style, and stop condition.

# Benchmarks

Use these as practical guardrails, not rigid claims.

## Practical Targets

- First-touch cold email: usually 4-6 short sentences.
- Subject line: usually 2-4 words.
- CTA: one low-friction ask.
- Sequence: usually 2-3 touches unless the evidence supports more.
- Proof: one relevant proof point beats a feature list.

## Common Failure Modes

- opening with the seller or vendor
- using personalization that does not connect to the problem
- asking for too much time too soon
- using unsupported pain claims
- sending the same follow-up repeatedly
- sounding polished but not specific

## Final Check

Read the email aloud. If it sounds like a campaign, cut it until it sounds like a person with a
specific reason to reach out.
